# Inventory Management System

A Django-based inventory management system that helps businesses manage their products, suppliers, stock levels, and sales efficiently.

## Features

- Product Management (CRUD operations)
- Supplier Management
- Stock Movement Tracking
- Sales Order Processing
- Real-time Stock Level Monitoring
- Data Validation
- User-friendly Interface

## Tech Stack

- Backend: Django
- Frontend: HTML, CSS, JavaScript
- Database: MongoDB
- Additional: django-mongoengine

## Prerequisites

- Python 3.8+
- MongoDB
- pip
